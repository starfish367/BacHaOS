# Cài LibreOffice theo yêu cầu trên Bạc Hà OS v1.0

## Mục đích

LibreOffice không được cài sẵn trong ISO để giảm dung lượng tải xuống. Bạc Hà OS vẫn giữ OnlyOffice làm bộ ứng dụng văn phòng sẵn dùng; khi cần LibreOffice, người dùng có thể cài thêm LibreOffice cùng gói tiếng Việt trực tiếp từ **BacHa OS Hello**.

## Thao tác trên desktop

| Bước | Thao tác thực tế | Kết quả cần thấy |
|---|---|---|
| 1 | Mở menu ứng dụng, tìm và mở **BacHa OS Hello**. | Cửa sổ chọn tác vụ xuất hiện. |
| 2 | Chọn **Cài LibreOffice theo yêu cầu**. | Hộp xác nhận giải thích LibreOffice không cài sẵn để ISO nhẹ hơn. |
| 3 | Chọn **Có** để tiếp tục. | Hệ thống tải danh sách gói và cài `libreoffice` cùng `libreoffice-l10n-vi`. |
| 4 | Chờ thông báo hoàn tất, rồi mở menu ứng dụng và tìm **LibreOffice**. | LibreOffice sẵn sàng sử dụng với gói ngôn ngữ tiếng Việt. |

> Cần có kết nối Internet trong lúc cài vì gói được tải từ kho phần mềm. Nếu thao tác thất bại, hãy kiểm tra mạng rồi mở lại BacHa OS Hello để thử lại.

## Quy tắc hình ảnh trên website

Sơ đồ bước có thể được dùng để minh họa luồng thao tác, nhưng chỉ ảnh chụp từ phiên boot ISO v1.0.0 đã xác minh mới được gắn nhãn là ảnh desktop, menu hoặc BacHa OS Hello thực tế. Không dùng splash Linux Mint hoặc mockup làm bằng chứng giao diện Bạc Hà OS.
