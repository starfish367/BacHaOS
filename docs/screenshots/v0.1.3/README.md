# Ảnh chụp desktop sau khi cài đặt — v0.1.3

Hai ảnh trong thư mục này được chụp từ **Bạc Hà OS v0.1.3 MATE** sau khi cài đặt vào ổ đĩa ảo riêng và boot lại từ ổ đã cài. Đây là ảnh desktop thật, không phải mockup hoặc preview hình nền.

ISO được kiểm tra SHA-256 trước khi cài đặt và tương ứng với bản phát hành [v0.1.3](https://github.com/starfish367/BacHaOS/releases/tag/v0.1.3). Tài khoản dùng để chụp là tài khoản minh họa cục bộ; không có dữ liệu cá nhân.

| Tệp | Nội dung |
| --- | --- |
| `bac-ha-os-v0.1.3-mate-desktop-sau-cai-dat.png` | Desktop MATE sau cài đặt, với wallpaper ruộng bậc thang và các launcher tích hợp. |
| `bac-ha-os-v0.1.3-bacha-os-hello-sau-cai-dat.png` | BacHa OS Hello chạy từ desktop sau cài đặt. Môi trường kiểm thử không có phân vùng NTFS, nên tiện ích hiển thị đúng trạng thái “Không tìm thấy phân vùng NTFS nào để gắn.” |

> Ảnh Cinnamon sẽ được bổ sung bằng ảnh chụp sau cài đặt thật khi ISO Cinnamon chính thức tải được hoàn chỉnh để xác minh.
